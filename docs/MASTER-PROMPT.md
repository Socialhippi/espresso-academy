# The one prompt

Run Claude Code from the repo root inside Cursor's terminal:

```
claude --permission-mode acceptEdits
```

(`.claude/settings.json` already allows pnpm, npx, git and the three MCPs, so it will not stop to ask. If it still pauses on something, answer once and it continues. Do not use `--dangerously-skip-permissions`; the allow-list is enough.)

Then paste everything below the line as a single message.

---

Read CLAUDE.md, every file in .claude/rules/, content/facts.md, content/data.ts, design/tokens.css and docs/images-manifest.md before doing anything. The frontend-design plugin is installed; use its guidance for craft, but the client's tokens and rules win on colour, type and radius. You are building the complete first version of the Espresso Academy India website, end to end, without stopping for questions. Where the client has not supplied a value (fee, date, duration, photo, testimonial, hours, email) the site must render a clean, branded TBC state, never a made-up value. When you finish, the site must be deployed to a Vercel preview URL and docs/STATUS.md must list every TBC item for the client.

Work in the ten phases below, in order. At the end of each phase: run `pnpm typecheck && pnpm lint && pnpm build`, fix everything, commit with a Conventional Commit message, and append a short entry to docs/STATUS.md. Do not skip the review steps; they are what make this launch quality rather than a template.
