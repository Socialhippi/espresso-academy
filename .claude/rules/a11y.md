# Accessibility rules (WCAG 2.2 AA)
- Landmarks: one header, nav with aria-label, one main, one footer. Skip link first in DOM.
- Real buttons and links; cards are links (an <a> wrapping content), not divs with onClick.
- Visible focus (blue ring) on every interactive element; never outline-none without replacement.
- Mobile sheet: focus trap, Escape closes, focus returns to the trigger. Accordion/tabs via shadcn (Base UI) patterns.
- Forms: visible labels, required in label text, errors adjacent + aria-describedby + aria-live polite, focus moves to first error, autocomplete attributes, no time limits.
- Contrast: text 4.5:1, UI 3:1. See design.md forbidden pairs.
- Touch targets 44x44 with 8px spacing. No hover-only content. Text resizes to 200% without loss.
- prefers-reduced-motion disables reveals and parallax. No autoplay video with sound; hero video (if any) is muted, has a poster, and a pause control.
- Alt text: meaningful or alt="" for decorative. Placeholders announce "Photo placeholder: <slot>".
- The level ladder and any diagram have a text equivalent.
